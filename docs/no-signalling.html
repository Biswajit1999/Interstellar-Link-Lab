03 / Interpretation

A falsification control, not a space modem

Without a classical side channel, Bob's local statistics cannot reveal Alice's choice. The second mode deliberately overwrites some of Bob's simulated results using Alice's setting. It should create measurable dependence—but that dependence is an injected conventional leak, not entanglement communication.

The browser uses deterministic pseudorandom Monte Carlo samples of an ideal mathematical state. No photon is transmitted. No relativistically separated measurement is carried out.

In the original quantum teleportation proposal, transmitting an unknown state requires both previously shared entanglement and an additional classical communication step [1].
